This function provides the weather of a given location by providing the 
zipcode of that given location.
This function requires zipcode as an argument, however user's often do not 
provide zipcode rather they provide location names.

If a location name is received, we should provide the zipcode of that location 
for the function to execute properly.

Example:
Input: What is the weather in New Delhi?
Output: New Delhi zipcode is 110001, so function should 110001 as an argument.
